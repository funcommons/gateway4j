# UI v2 实施契约（子 agent 唯一事实源）

> 本文件是 /loop 无人值守实施的分工契约。所有子 agent 动工前必读本文 + `界面重构方案.md` §6/§7 + 对应原型 `gateway4j-admin-ui/prototype-v2/*.html`。
> 主 agent 只做调度与汇报；子 agent 每个任务只做一件事。

## 0. 铁律（违反=打回）

1. **旧 UI 零行为变化**：不修改 `src/views/`（旧页面）、不改任何 `data-testid`、不删路由。允许的旧文件改动仅限：`src/router/index.ts`（追加 v2 路由表）、`src/layouts/MainLayout.vue`（顶栏加一个「新版体验」入口，不改既有逻辑）、`src/locales/*.ts`（追加 key）。
2. **业务页只用 SDK 组件**（`.claude/skills/fc-web-sdk/SKILL.md`）：禁 `el-card/el-table/el-dialog/…` 直用；颜色圆角阴影全部走 token；Hallmark 门槛（对比度/焦点环/26a/49a/PRM/无 emoji 图标）同样适用 v2。
3. **每个子 agent 一件事**：写测试 / 写业务 / 跑测试 / 修复 / 评审，五种任务类型不得混合。
4. **单步业务代码 ≤1000 行**（测试代码不计）。超过就拆步。
5. **权限模型沿用**：v2 路由 `meta.permission` 与旧路由一致；守卫逻辑复用现有 `router.beforeEach`（含 `auth.init()`），禁止复制一份新守卫。
6. **i18n 双语**：`zh-CN.ts` / `en-US.ts` 同步加 key，禁止硬编码中文。
7. 后端改动遵守 `mc-java-spec` / `fwk4j-*` 契约：`ApiResponse` 信封、`@RequiresToken`、`ApiCode`、Flyway 版本化迁移、写操作幂等。

## 2. LayoutV2 骨架（S1）

- `src/layouts/LayoutV2.vue`：左分组导航（总览/路由/插件/可观测/系统，参照原型 01 侧栏）+ 顶栏（面包屑 + ⌘K 搜索占位 + 通知 + 用户）。分组用 i18n key `v2.nav.*`。
- S1 阶段每个 v2 页面先用统一的 `V2PagePlaceholder.vue`（居中标题 + 对应原型截图路径提示 + 「该模块在后续步骤实现」），后续步骤逐个替换为真页面 —— 保证每步 ≤1000 行。
- 侧栏 active 态走 `route.name`；折叠态 S1 不做（原型未含）。
- **i18n key 树（S1-R 裁决后固定，v2 全部页面沿用）**：分组 `v2.nav.group.{overview,routes,plugins,observability,system}`；侧栏叶子 `v2.nav.{overview,routes,wizard,pluginChain,monitor,debug}`；返回旧版 `v2.layout.backToLegacy`；顶栏入口 `v2.topbar.tryV2`（testid `v2-entry`）；页面标题 `v2.page.*`；占位文案 `v2.placeholder.*`。新增 key 必须双语同步，命名先查这棵树再 invent。

## 3. 测试与评审流程（每步）

1. **T-agent**（写测试）：按契约 + 原型写 `*.test.ts`（vitest，colocated）。先红是预期。只测本步对应代码。
2. **C-agent**（写业务）：实现到契约为止，不跑测试。
3. **R-agent**（跑测试）：`npx vitest run <本步文件>` + `npx vue-tsc --noEmit`（基线 16 错不得新增）+ 对文件 `npx eslint`。输出失败清单。
4. **F-agent**（修复）：只改失败项，一轮一提交粒度。回到 3，**≤4 轮**。
5. **V-agent**（评审）：对照原型截图与契约逐项评审，输出 P0 阻断/P1 重要/P2 次要/P3 打磨 分级建议；无 P0~P2 则本步收工，主 agent commit。P3 记录到该步 PR 描述，最后统一打磨。
6. **全量回归触发**：代码更新 >10% 或 >1000 行或 >10 个任务 → G-agent 跑全量（前端：`vitest run` 全部 + vue-tsc + eslint + `vite build`；后端：对应模块 `mvn -pl … test`）。非阻塞，失败则插入 F-agent。
