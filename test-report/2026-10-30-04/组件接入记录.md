## 顺带修掉：remixicon 图标字体缺失（既有缺陷）

- **现象**：SDK 的 `FcIcon` 与 SDK 内部组件统一用 remix-icon class（`ri-*`），但本项目**从未安装 remixicon** → 全库 51 处 `ri-*` 图标渲染为**空的 `<i>` 元素**（含侧栏导航图标）。
- **依据**：源项目 ldx2 的 `package.json` 含 `remixicon@^4.9.1`，`main.ts` 引入 `remixicon/fonts/remixicon.css` —— 这是 SDK 的既定图标契约，不是本项目新引入的第三方选型。
- **处理**：`npm i remixicon@^4.9.1` + `main.ts` 引入字体样式。
- **实证**：修复前 `<i class="ri-menu-fold-line">` 宽 0；修复后 `font-family: remixicon`、宽 16px（见截图 01-header-with-icons.png）。

## 值得记住的一条

**图标类名不等于图标**：本项目此前 51 处 `ri-*` 类名一直是"空元素"，因为字体没装。SDK 合入把这类问题放大了 —— 接 SDK 组件时，**连带检查它依赖的运行时资源**（图标字体、CSS 变量、全局样式），别只看组件 API 对不对。
